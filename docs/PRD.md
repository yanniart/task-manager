## 1. 개요

앱 이름은 **MyTask**예요(v0.9). 화면 맨 위 제목, 홈 화면 아이콘 이름, 브라우저 탭 제목, 내보내기 파일 이름에 써요.

매일 10~20개의 할 일을 관리하는 **개인용 웹 앱**이에요.
주로 **휴대폰 브라우저**에서 쓰고, 홈 화면에 추가하면 앱처럼 열 수 있어요.
새로고침하거나 브라우저를 다시 열어도 데이터가 남아 있어야 해요.

## 2. 목표

| 목표 | 성공 기준 |
|---|---|
| 한 손으로 빠르게 할 일을 적는다 | + 버튼 → 입력 → 저장까지 3번 터치 안에 끝난다 |
| 오늘 얼마나 했는지 한눈에 본다 | 화면 위쪽에 오늘의 진행률(%)과 막대가 항상 보인다 |
| 일의 종류를 나눠 본다 | 업무/개인/공부 필터로 목록을 바로 걸러 볼 수 있다 |
| 못 끝낸 일을 놓치지 않는다 | 다음 날 앱을 열면 어제 못 끝낸 일이 오늘 목록에 들어와 있다 |
| 매번 같은 일을 다시 적지 않는다 | 반복 일정으로 등록하면 해당 날짜에 자동으로 생긴다 |
| 데이터를 잃지 않는다 | 새로고침·브라우저 재시작 후에도 목록이 그대로다 |

### 하지 않을 것 (범위 밖)

- 로그인, 회원가입, 여러 기기 간 동기화
- 서버, 데이터베이스
- 알림 (v0.3에서 제외, [TL-009](tech-log.md#tl-009))
- 여러 사람이 함께 쓰는 기능
- 달력 화면, 지난 날짜 기록 통계

## 3. 사용자와 사용 환경

- 하루 할 일을 직접 정리하는 한 사람
- **주 사용 환경: 휴대폰** (Android Chrome, iPhone Safari)
- PC 브라우저에서도 깨지지 않고 쓸 수 있으면 충분해요
- 화면 너비 기준: 360px ~ 430px에 맞춰 설계하고, 그보다 넓으면 가운데 정렬해요

## 4. 핵심 개념

- **오늘 목록**: 앱은 항상 "오늘" 날짜의 할 일을 보여줘요. 모든 할 일에는 날짜가 붙어요.
- **이월**: 지난 날짜의 미완료 할 일을 오늘로 옮기는 것.
- **반복 규칙**: "매일 / 평일 / 매주 월·수" 같은 규칙. 규칙에 맞는 날이 되면 그날의 할 일이 자동으로 하나 생겨요.

## 5. 기능 요구사항

### F1. 할 일 추가

- 화면 오른쪽 아래 **+ 버튼**을 누르면 아래에서 입력 시트가 올라와요.
- 입력 시트 항목: 내용, 카테고리(업무/개인/공부), 반복(선택)
- 카테고리 기본값은 마지막으로 고른 값이에요.
- 빈 내용이나 공백만 있으면 저장 버튼이 비활성화돼요.
- 내용은 최대 100자예요.
- 새 할 일은 **이월된 할 일 바로 아래**에 나와요. 이월된 할 일이 없으면 맨 위예요.

### F2. 할 일 수정

- 할 일 내용을 탭하면 수정 시트가 올라와요. 추가 시트와 모양은 같지만 **반복 줄은 보이지 않아요.**
- 내용과 카테고리를 바꿀 수 있어요.
- 반복 규칙으로 생긴 할 일이면 반복 줄 자리에 "🔁 매주 월·수 반복 · **반복 일정 관리에서 수정**" 안내가 보이고, 누르면 반복 일정 관리 화면의 해당 규칙으로 이동해요.
- 일반 할 일을 나중에 반복으로 바꾸는 기능은 없어요. 반복 일정 관리에서 새 규칙을 만들어요.
- 반복 규칙으로 생긴 할 일을 고치면 **그날의 할 일만** 바뀌어요. 규칙 자체는 F8의 반복 일정 관리에서 바꿔요.

### F3. 할 일 삭제

- 수정 시트 아래쪽 **삭제** 버튼으로 지우고, 확인 창으로 한 번 더 물어봐요.
- **완료한 항목 모두 지우기** 버튼으로 완료된 항목을 한꺼번에 정리해요 (확인 창 있음).
- 완료한 할 일은 **사용자가 지울 때까지 남아 있어요.** 날짜가 바뀌어도 자동으로 지우지 않아요.

### F4. 완료 체크

- 각 항목 왼쪽의 큰 체크 버튼(터치 영역 44px 이상)으로 완료/미완료를 바꿔요.
- 완료된 항목은 취소선이 그어지고 흐리게 보이며, 목록 아래쪽 **완료** 구역으로 내려가요.
- 완료를 취소하면 미완료 목록의 **맨 아래**로 돌아가요.
- 체크할 때 가벼운 진동을 줘요 (지원하는 기기만).

### F5. 카테고리 분류

- 카테고리는 **업무 / 개인 / 공부** 세 가지로 고정해요.
- 카테고리마다 색 배지를 달아요 (업무 파랑, 개인 초록, 공부 주황).
- 목록 위 필터 탭: **전체 / 업무 / 개인 / 공부**. 가로로 스크롤되지 않게 한 줄에 다 들어가요.
- 마지막으로 고른 필터는 새로고침해도 유지돼요.

### F6. 진행률 보기

- **오늘** 날짜의 할 일만 계산해요.
- 전체 진행률: `완료 수 / 전체 수`를 퍼센트와 막대로 보여줘요 (예: `7 / 12 완료 · 58%`).
- 카테고리별 진행률: 업무·개인·공부 각각의 완료 수/전체 수를 작게 보여줘요.
- 할 일이 0개면 "할 일을 추가해 보세요" 안내를 띄우고 진행률은 0%로 보여줘요.
- 변경할 때마다 바로 다시 계산하고, 100%가 되면 축하 문구를 보여줘요.

### F7. 미완료 할 일 이월

- 앱을 열 때(또는 켜 둔 채로 자정이 지날 때) 지난 날짜의 **미완료** 할 일을 오늘 날짜로 옮겨요.
- 옮겨진 할 일에는 **"이월"** 표시와 원래 날짜(예: `11/10부터`)를 붙여요.
- 이월된 할 일은 미완료 목록 맨 위에 모여요.
- 단, **반복 규칙으로 생긴 할 일은 이월하지 않아요.** 오늘 몫이 새로 생기기 때문이에요. 지난 날짜의 미완료 반복 할 일은 조용히 정리돼요.
- 지난 날짜의 **완료** 항목은 그대로 두고, 목록 맨 아래 **"이전에 완료한 항목 (n)"** 접힘 구역에 보여줘요. 진행률 계산에는 들어가지 않아요.

### F8. 반복 일정

- 추가 시트에서 반복을 고를 수 있어요: **반복 안 함 / 매일 / 평일(월~금) / 매주 (요일 여러 개 선택)**
- 반복을 고르고 저장하면 **반복 규칙**이 만들어지고, 오늘이 규칙에 맞으면 오늘 할 일도 바로 생겨요.
- 앱을 열 때 오늘 날짜에 맞는 규칙마다 할 일을 하나씩 만들어요. 같은 날 같은 규칙으로 두 번 만들지 않아요.
- 반복으로 생긴 할 일에는 🔁 표시가 붙어요.
- 자동으로 생긴 할 일도 새 할 일처럼 **이월된 할 일 바로 아래**에 들어가요.
- 반복 일정 관리 화면에도 **+ 새 반복 일정** 버튼이 있어요.
- **반복 일정 관리** 화면(헤더 오른쪽 🔁 모양 버튼)에서 규칙 목록을 보고 수정·일시정지·삭제할 수 있어요.
  - 규칙을 수정하면 **다음 생성분부터** 반영돼요. 오늘 이미 생긴 할 일은 그대로예요.
  - 규칙을 삭제해도 이미 생긴 할 일은 남아요.

### F9. ~~알림~~ (v0.3에서 제거)

- 서버 없이는 앱이 닫혀 있을 때 알림을 보낼 수 없어서 넣지 않기로 했어요 ([TL-009](tech-log.md#tl-009)).
- 번호는 다른 문서의 참조가 어긋나지 않도록 비워 둬요.

### F10. 순서 바꾸기 (드래그)

- 각 항목 오른쪽의 **⠿ 손잡이**를 누른 채 끌어서 순서를 바꿔요 (터치·마우스 모두).
- 미완료 항목끼리만 순서를 바꿀 수 있어요. 완료 구역은 완료한 순서대로 놓여요.
- 바꾼 순서는 저장돼요.
- 드래그로 정한 순서가 기본 규칙보다 우선이에요. 예를 들어 이월된 할 일을 아래로 옮기면 그 자리에 그대로 있어요.

#### 목록 순서 규칙 정리

| 상황 | 들어가는 자리 |
|---|---|
| 날짜가 바뀌어 이월된 할 일 | 미완료 목록 맨 위 (원래 날짜가 오래된 것부터) |
| 새로 추가한 할 일 / 반복으로 생긴 할 일 | 맨 위에 모여 있는 이월된 할 일 바로 아래 |
| 완료를 취소한 할 일 | 미완료 목록 맨 아래 |
| 드래그한 할 일 | 놓은 자리 |
- 필터가 켜져 있을 때 바꾸면, 보이는 항목들 사이의 순서만 바뀌어요.

### F11. 데이터 저장

- 모든 변경은 즉시 브라우저 `localStorage`에 저장해요.
- 저장된 데이터가 깨져 있으면 빈 목록으로 시작하고, 깨진 원본은 백업 키에 따로 남겨요.

### F12. 화면 모드 전환 (v0.5 추가)

- 헤더 오른쪽 버튼으로 화면 모드를 바꿔요. 누를 때마다 **시스템 설정 → 라이트 → 다크 → 시스템 설정** 순서로 돌아가요.
- 버튼 아이콘은 지금 모드를 보여줘요: 시스템 설정(반쪽 원), 라이트(해), 다크(달).
- 고른 모드는 저장돼서 새로고침해도 유지돼요. 처음에는 "시스템 설정"이에요.

### F13. 할 일 검색 (v0.6 추가)

- 헤더의 🔍 버튼을 누르면 검색창이 열려요. 입력하는 대로 목록이 걸러져요(입력이 잠깐 멈추면 찾아요).
- 오늘 미완료·오늘 완료·이전에 완료한 항목 모두에서 찾아요. 카테고리 필터와 함께 쓸 수 있어요.
- 대소문자·띄어쓰기 개수는 무시하고, 낱말을 여러 개 쓰면 모두 들어간 것만 보여요("보고서 메일").
- 맞는 부분을 강조하고, 목록 위에 "검색 결과 n개"를 보여줘요. 없으면 "'…'에 맞는 할 일이 없어요".
- 검색 중에도 끌어서 순서를 바꿀 수 있어요. 보이는 항목끼리만 섞여요(F10의 필터 규칙과 같아요).
- 진행률은 검색과 상관없이 오늘 전체 기준이에요. 검색어는 저장하지 않아요.
- Esc: 글자가 있으면 지우고, 비어 있으면 검색창을 닫아요.

### F14. 보기 정렬 (v0.6 추가)

- **필터 탭 바로 아래, 목록 오른쪽 위의 정렬 아이콘(⇅)**을 누르면 작은 메뉴가 열려요(v0.7). 새로고침해도 유지돼요.
- 직접 정렬일 때는 아이콘만 보이고, 다른 정렬이면 아이콘이 파랗게 바뀌며 옆에 정렬 이름이 붙어요(예: "⇅ 생성일순").

| 정렬 | 보이는 순서 |
|---|---|
| 직접 정렬 (기본) | 드래그로 정한 순서 (F10) |
| 생성일순 | 먼저 만든 할 일부터 |
| 카테고리순 | 업무 → 개인 → 공부 (같은 카테고리 안에서는 직접 정렬 순서) |
| 완료 상태순 | 미완료·완료 구역을 **한 목록으로 합쳐** 미완료 먼저, 완료 나중 |

- 정렬은 **보는 순서만** 바꿔요. 드래그로 정한 순서는 그대로 남아서 "직접 정렬"로 돌아오면 원래대로예요.
- 직접 정렬이 아닐 때는 드래그 손잡이를 숨겨요. 직접 정렬로 돌아가려면 같은 메뉴에서 "직접 정렬"을 골라요.

### F15. 데이터 내보내기·가져오기 (v0.6 추가)

- 더보기 → **JSON으로 내보내기**: 할 일·반복 일정·휴지통·설정을 `task-manager-날짜.json` 파일로 내려받아요.
- 더보기 → **JSON 가져오기**: 파일을 고르면 개수를 보여주며 확인한 뒤, **지금 데이터를 통째로 바꿔요.**
  - 바꾸기 전 데이터는 자동으로 백업해 두고(최근 3번), 알림의 **되돌리기**로 바로 되돌릴 수 있어요.
  - 잘못된 파일(JSON 아님, 다른 앱 파일, 더 새로운 버전, 깨진 내용, 2MB 초과)은 이유를 알려주고 가져오지 않아요.
  - 가져온 파일의 날짜가 지났으면 이월·반복이 오늘 기준으로 맞춰져요(F7, F8).

### F16. 중복 확인 경고 (v0.6 추가)

- 추가·수정 시트에서 **오늘 미완료 목록에 같은 내용**이 있으면 입력창 아래에 알려줘요.
- 반복 일정을 만들거나 고칠 때는 **같은 이름의 반복 일정**이 있으면 알려줘요.
- 막지는 않아요. 같은 일을 두 번 하는 경우도 있어서 그래도 저장할 수 있어요.
- 앞뒤 공백·띄어쓰기 개수·대소문자는 무시하고 비교해요. 완료한 할 일과 같은 건 알리지 않아요(다시 하는 일일 수 있어서).

### F17. 삭제 복구 (휴지통) (v0.6 추가)

- 할 일·반복 일정을 지우면 바로 지우지 않고 **휴지통**으로 보내요.
- 지운 직후에는 알림에 **되돌리기**가 6초 동안 보여요. "완료한 항목 모두 지우기"는 한 번에 되돌려요.
- 더보기 → 휴지통에서 하나씩 **복구**하거나 **휴지통 비우기**(확인 창)를 할 수 있어요.
- 휴지통은 **30일, 최대 100개**까지 보관하고 그보다 오래된 것은 저절로 지워져요.
- 되살린 미완료 할 일은 원래 순서 자리로 돌아가요. 지난 날짜의 것이면 오늘로 데려오고 "이월" 표시를 붙여요.

### F18. 키워드 기반 카테고리 자동 분류 (v0.8 추가)

- 할 일을 **추가**할 때(새 반복 일정 포함) 입력이 잠깐 멈추면, 내용에 들어 있는 키워드로 카테고리 칩을 골라 줘요.
  - 예: "팀 **회의** 준비" → 업무, "엄마 **생일** 선물" → 개인, "**영단어** 30개" → 공부
  - 칩 아래에 "'회의' 키워드로 업무를 골랐어요. 바꾸려면 칩을 누르세요."라고 알려줘요.
  - 키워드가 없어지면(지우거나 고치면) 처음 카테고리로 돌아가요.
  - 입력하자마자 저장해도 자동 분류가 적용돼요.
- **직접 고른 것이 우선**: 칩을 한 번 직접 누르면 그 시트에서는 더 이상 자동으로 바꾸지 않아요.
- **수정할 때는 자동으로 바꾸지 않아요.** 이미 있는 할 일의 카테고리가 몰래 바뀌지 않게요.
- 자동으로 고른 카테고리는 다음 추가의 기본값(F1 "마지막으로 고른 값")을 바꾸지 않아요. 직접 고른 값만 기억해요.
- 여러 카테고리 키워드가 함께 있으면 ① 긴 키워드 ② 앞에 나온 키워드 ③ 업무→개인→공부 순서로 골라요.
- 대소문자·띄어쓰기·조사("회의를")는 신경 쓰지 않아도 돼요.
- **더보기 → 자동 분류**에서
  - 켜고 끌 수 있어요(처음엔 켜짐).
  - 카테고리별 키워드를 쉼표로 고칠 수 있어요(키워드당 20자, 카테고리당 50개까지). 입력을 마치면 저장돼요.
  - 같은 키워드가 여러 카테고리에 있으면 어느 쪽이 쓰이는지 알려줘요.
  - "기본 키워드로 되돌리기"(확인 창).
- 기본 키워드는 카테고리마다 16개씩 넣어 두었어요. 한 글자 키워드는 엉뚱하게 걸리기 쉬워서(예: "책" → "책상 정리") 넣지 않았어요.

## 6. 화면 구성 (휴대폰 기준)

```
┌────────────────────────────┐
│ MyTask          🔍 ◐ 🔁 ⋯ │  ← 🔍 검색(F13), ◐ 화면 모드(F12), 🔁 반복 일정, ⋯ 더보기(F14·F15·F17)
│ 11.11(수)                  │  ← 버튼이 4개라 날짜는 제목 아래 줄
│ ████████░░░░ 7/12 · 58%    │
│ 업무 3/5 개인 2/4 공부 2/3 │
│ [전체][업무][개인][공부]   │
│ 검색 결과 3개          ⇅   │  ← 왼쪽 검색 결과 수(검색 중), 오른쪽 정렬 아이콘(F14)
├────────────────────────────┤
│ ○ 보고서 마무리 이월 11/10 ⠿│
│   업무                     │
│ ○ 영단어 30개  🔁         ⠿│
│   공부                     │
│ ○ 장보기                  ⠿│
│   개인                     │
│ ── 완료 (2) ────────────── │
│ ● ~~운동~~                 │
│ ▸ 이전에 완료한 항목 (3)   │
│      [완료한 항목 모두 지우기]│
│                       ( + )│  ← 떠 있는 추가 버튼
└────────────────────────────┘

추가/수정 시트 (아래에서 올라옴)
┌────────────────────────────┐
│ 할 일 [________________]   │
│ 카테고리 (업무)(개인)(공부)│
│ '회의' 키워드로 업무를 골랐어요│ ← 추가할 때 키워드가 있으면 (F18)
│ 반복 (안 함)(매일)(평일)(매주)│
│          월 화 수 목 금 토 일│ ← 매주일 때만
│ [삭제]            [저장]   │ ← 삭제는 수정일 때만
└────────────────────────────┘
```

- 반복 줄은 **추가할 때만** 보여요. 수정할 때는 그 자리에 반복 안내가 보이거나(반복 할 일) 아무것도 없어요(일반 할 일).
- 버튼과 체크 등 누르는 곳은 모두 44px 이상이에요.
- 아이폰 노치·홈 바 영역을 피해서 배치해요.
- 처음에는 시스템 다크 모드를 따라가고, 헤더 버튼으로 라이트·다크를 직접 고를 수도 있어요 (F12).

## 7. 기술 요구사항 (요약)

- **순수 HTML / CSS / 자바스크립트**만 사용해요. 프레임워크와 빌드 도구는 쓰지 않아요.
- 홈 화면 추가와 오프라인 사용을 위해 **PWA**(manifest + 서비스 워커)로 만들어요.
- 파일을 기능별로 나누려고 ES 모듈을 써서, 더블클릭 대신 **로컬 서버 또는 HTTPS 주소**로 열어야 해요.
- 자세한 구조, 데이터 형식, 모듈 설계는 [TRD](TRD.md)에 있어요.
- **성능 (v0.6)**: 할 일이 100개 이상이어도 부드러워야 해요. 휴대폰 수준(CPU 4배 느리게)에서 300개일 때 체크·한 칸 옮기기가 50ms 안에 끝나고, 검색은 입력이 멈출 때 한 번만 다시 그려요(디바운스). 측정값은 [TRD 5.14](TRD.md)에 있어요.
